# StudyAI — AI-powered study assistant

Upload any lecture PDF and chat with it using Claude AI.
Built for AUT students in Tashkent. Free and open source.

## Features
- Upload lecture PDFs and ask questions
- Auto-generate flashcards
- Exam prep questions
- One-click summaries

## Tech stack
React · Vite · Claude API · Vercel

## Run locally

1. Clone the repo
   git clone https://github.com/oktambek7/study-assistant.git
   cd study-assistant

2. Install dependencies
   npm install

3. Add your API key
   Copy .env.example to .env.local and add your Anthropic API key inside

4. Start the app
   npm run dev
